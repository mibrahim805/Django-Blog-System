# Social Blog Platform

A feature-rich social blogging platform built with Django, focused on personalized content, social interaction, and real-time notifications.

---

# 🚀 Technologies Used

- Python
- Django
- Django Templates
- Django ORM
- Django Channels (WebSockets)
- SQLite
- CKEditor
- HTML5
- CSS3
- JavaScript
- Bootstrap
- RSS Feed System

---

# ✨ Features

## 🔐 Authentication & User Management

- User Registration
- User Login/Logout
- Custom User Model
- Password Reset via Email
- User Profile System

---

## 📝 Blog/Post System

- Create Posts
- Edit Posts
- Delete Posts
- Rich Text Editor (CKEditor)
- Published/Unpublished Posts
- User-specific Posts
- Post Timestamps

---

## 📂 Categories & Interests

- Category-based Posts
- Multiple Categories Support
- Interest Selection System
- Personalized Content Feed

---

## ❤️ Social Features

- Follow/Unfollow Users
- Followers & Following System
- User Interaction Features

---

## 💬 Comment System

- Add Comments
- Edit/Delete Comments
- Nested Replies
- Comment Approval System

---

## 👍 Like System

- Like/Unlike Posts
- Like Comments
- Dynamic Like Counts

---

## 🔔 Real-Time Notifications

- Live Notifications using WebSockets
- Mark Notifications as Read
- Unread Notification Counter

---

## 📌 Personalization Features

- Save/Favorite Posts
- Saved Posts Page
- "Not Interested" Feature
- Personalized Feed Recommendations

---

## 📰 Feed & Content Delivery

- Personalized News Feed
- RSS Feed Support
- Category Filtering
